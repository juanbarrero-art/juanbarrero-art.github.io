# Bienvenido

Este es el **primer post** de mi blog de ciberseguridad. Un espacio para documentar
lo que aprendo sobre **análisis de malware**, **Windows internals** y defensa.

## Qué encontrarás

- Writeups de análisis (estático y dinámico).
- Notas de laboratorio y experimentos.
- Conceptos de **Blue Team** y **Red Team**.
- Scripts y herramientas propias.

## Enfoque

Me enfoco en **Blue Team** con base en **Red Team**: entender cómo atacan para
defender mejor. Si quieres empezar, este fragmento resume la idea:

```python
def defender(conocer_el_ataque: bool) -> str:
    return "mejor defensa" if conocer_el_ataque else "a ciegas"
```

> Aprender a romper para poder defender.
